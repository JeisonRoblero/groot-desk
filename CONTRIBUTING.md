# Contributing to proot-desk

Thanks for taking the time to contribute! Here's everything you need to know.

---

## Branches

| Branch | Purpose |
| --- | --- |
| `main` | Stable, production-ready code |
| `develop` | Active development - target this for your PRs |

**Always open Pull Requests against `develop`, not `main`.**

---

## How to Contribute

1. **Fork** the repository

2. **Clone** your fork locally

    ```bash
    git clone https://github.com/YOUR_USERNAME/proot-desk.git
    cd proot-desk
    ```

3. **Create a branch** for your change

    ```bash
    git checkout -b feature/your-feature-name
    ```

4. **Make your changes** and test them on a real Termux environment

5. **Commit** with a clear message

    ```bash
    git commit -m "feat: short description of what you did"
    ```

6. **Push** to your fork

    ```bash
    git push origin feature/your-feature-name
    ```

7. **Open a Pull Request** from your branch (`feature/your-feature-name`) to `develop` on the original repository

---

## Commit Message Style

Keep it simple and descriptive. Use a short prefix:

| Prefix | When to use |
| --- | --- |
| `feat:` | New feature |
| `fix:` | Bug fix |
| `docs:` | Documentation changes |
| `refactor:` | Code cleanup without behavior change |
| `chore:` | Maintenance tasks |

---

## Bug Reports & Feature Requests

Open an [issue](https://github.com/JeisonRoblero/proot-desk/issues) and describe:

- What you expected to happen
- What actually happened
- Your device, Android version, and Termux version

---

## Questions

Feel free to open an issue if something is unclear. All skill levels are welcome!
